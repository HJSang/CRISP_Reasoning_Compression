Leading hypothesis: OPD selectively repairs a mixed PI-induced change

A worse benchmark score does not mean that every learned change is harmful. PI might improve some solution patterns while also inducing inappropriate confidence, reference-dependent shortcuts, wording or termination behavior. Matching the unprivileged original teacher on the student's own prefixes may remove the harmful components faster than the useful ones. The resulting model can retain a useful residual change and outperform its anchor.

This is a hypothesis about a partial return. OPD optimizes token-distribution matching on sampled prefixes, not benchmark accuracy. Exact equality with the original model's output distribution on evaluation prompts would imply equal expected accuracy under the same sampling protocol. Our finite updates do not produce that equality. Lower training KL is not proof of moving closer on every evaluation prompt: questions and on-policy prefixes change between updates. The existing local-curvature model and numerical example show how unequal contraction could produce the observed pattern; they do not establish that real Adam updates follow that mechanism.

A second explanation is more generic: many perturbations might move the model into a state where short distillation acts as useful regularization. The observed PI → OPD sequence alone cannot tell us whether correct mathematical information supplied by PI is necessary. Deliberately selecting a worse warm-up would bias this test; retain every prespecified warm-up regardless of its score.

The user's two cyclic recipes: keep the teacher fixed within a complete cycle

Let θ₀ be the original model, θc the student entering cycle c, and φc the frozen teacher used in that cycle. The student sees only the problem throughout. The PI teacher sees the worked solution as extra context; the OPD teacher sees no solution. Both teacher views score the same student-generated prefixes.

θc → PI(φc, a updates) → warmed student → no-PI OPD(φc, b updates) → θc+1
Fixed-original policy: φc = θ₀ for every cycle.
Cycle-refresh policy: φ₀ = θ₀; after a complete cycle, φc+1 = detached copy of θc+1.

Carry the resulting student forward in both policies. Do not reset it to θ₀ between cycles. Refreshing the teacher immediately after PI would make it equal to the warmed student at OPD start, eliminating the intended discrepancy in an exact implementation. The default reset variant clears Adam's first and second moments and bias-correction counters at each phase start; it does not reset the student's weights. That default uses a constant learning rate of 5×10⁻⁶, with no warmup. The new decay variants instead share one continuous global schedule. Carrying Adam state and adding a continuous LR decay are distinct changes.

Why the suggestion could matter: in standard Adam, the first update after a complete reset has bias-corrected moments m̂=g and v̂=g², giving a coordinate update −ηg/(|g|+ε). For |g| much larger than ε, a small gradient can still produce a step near η. Preserving the moments and their counters changes that behavior; it does not guarantee smaller steps or a falling LR. These statements follow from Adam, Algorithm 1. Whether repeated resets hinder our PI/OPD recipe remains an experimental question.

Competing hypotheses: repeated resets plus constant LR could keep disturbing useful accumulated changes, so carried state and a global decay might improve later cycles. Conversely, PI momentum may initially push against the new no-PI objective, so resetting can help the four-update recovery. A plateau could also reflect the fixed original teacher pulling back accumulated learning, or an unsuitable PI/OPD ratio. The existing pilots used fresh Adam in both branches and contain no reset-versus-carry comparison or LR sweep; they do not establish that 5×10⁻⁶ is too large or that saturation is inevitable.

A falsifiable theory: unequal contraction of PI-induced changes

Let θ* = θ₀ + δ. PI training might add a mixture of useful and harmful changes. Around θ₀, the original-teacher forward KL on a fixed set of student prefixes has the local approximation below. F is the positive-semidefinite curvature matrix of the teacher-matching loss: in the same-backend softmax model at equality, it is a Fisher-type matrix averaged over those prefixes.

Lreturn(θ₀ + δ) ≈ ½ δᵀFδ
δk+1 ≈ (I − ηF)δk
ΔUk ≈ Σi giδi(1 − ηλi)k

The eigenvalues λ describe how strongly the teacher loss penalizes different directions; g is the local gradient of a smooth held-out utility proxy. If harmful utility components lie in directions that shrink quickly, while useful components shrink slowly, an initially harmful δ can become helpful after a few return updates. Eventually exact return to θ₀ removes the gain. This offers an explanation for a transient student-above-teacher effect without treating the distillation step as a source of new task information: PI supplied information earlier.

Assumptions matter: this is a local approximation on fixed prefixes with detached state sampling, exact same-backend teacher/student distributions and sufficiently small stable steps. Actual Adam has a changing preconditioner, clipping changes the effective step size, and on-policy prefixes change with the student. With a fixed preconditioner P, the analogous update contains PF, not F alone. Hard top-k/top-p boundaries also make actual evaluation utility only piecewise smooth. Therefore this is a hypothesis and a useful mathematical model, not a theorem about the completed runs.

How to make the termination ablation exact

Let S contain the actual stop-token IDs used by generation. With q the teacher and p the student, the full KL decomposes as:

KL(q‖p) = KLBernoulli(q(S)‖p(S))
+ q(S) KL(q(·|S)‖p(·|S))
+ (1−q(S)) KL(q(·|¬S)‖p(·|¬S)).

For a single stop token, the within-S term is zero. Log all terms with the original sample/token normalization. Stop-only training uses the Bernoulli term; content-only training uses the teacher-weighted conditional non-stop term. Shared-parameter updates can still indirectly change stop behavior, so verify resulting stop probabilities and lengths rather than assuming perfect separation. Record exact response token IDs prospectively for any budget-prefix replay. Decoding then retokenizing old response text is not guaranteed to reconstruct the generated token tape.

One objective describes all three compositions

At a position on a current-student response, let p be the student distribution without PI, qI the frozen original teacher with PI, and r the same frozen original teacher without PI. Both teacher prefixes receive the identical generated response token IDs. Teachers and sampled prefixes are detached for the update. Keep full-vocabulary forward KL, scoring temperature one, and the established per-sample token mean.

Lλ = λ KL(qI ‖ p) + (1−λ) KL(r ‖ p),   0 ≤ λ ≤ 1
qλ = λ qI + (1−λ) r
∇student logitsLλ = p − qλ = (p − r) − λ(qI − r).

λ=1 gives PI training; λ=0 gives no-PI return OPD. The last expression separates attraction to the original model from the PI-induced probability correction measured at the same teacher checkpoint. This connects to the earlier PI/checkpoint separation question without dividing by small token probabilities. A probability mixture has the same student gradient as the weighted sum of forward KL losses on a fixed detached tape; their scalar loss values differ by a teacher-only term. Averaging logits produces a different geometric mixture and must not be substituted silently. The mixture needs both teacher forward passes, so equal updates do not imply equal GPU cost.

Why timing may matter, and what we would learn

A small PI step can move parameters in both useful and harmful directions. Returning toward the original distribution may contract those components at different rates; a cycle could add useful changes repeatedly while limiting harmful ones. A simultaneous mixture may prevent the excursion altogether, or suppress the useful change before it develops. These are competing hypotheses. Sequential and mixed training are not equivalent even with equal total PI weight: parameters, on-policy prefixes, clipping and Adam moments change between updates. Too much exact no-PI matching to a fixed original teacher can eventually erase improvement. “More return training” is therefore not guaranteed to help.

If cycles beat a single stage at matched exposure, timing is worth studying; if the mixture wins, continuous regularization may be sufficient. Neither result by itself proves semantic PI retention. Length-matched shuffled PI followed by OPD, a matched generic perturbation, and KL-matched parameter interpolation remain the strongest controls for that interpretation. The earlier unit-strength transported PI-only target performed poorly in the single-source study; do not treat that ratio construction as already validated. A smaller PI correction or probability mixture is a new test.

Repeated return to the original model may limit accumulation of new capabilities. After selecting a schedule, compare a permanently frozen teacher with a lagged teacher frozen within each cycle, or an EMA teacher; use the same teacher weights for the with-PI and no-PI views. Keep teacher refresh as its own factor so gains are not confused with checkpoint drift. SDFT reports that an EMA teacher improves stability relative to directly using the current student in its experiments, but those tasks and training settings differ from ours. SDFT teacher-choice ablation.

Only after this comparison should we tune PI:no-PI dose (for example 1:3, 1:1 and 3:1), try a smoothly decaying λ, or learn a controller from independent diagnostic signals. Teacher KL falling is not evidence that task accuracy rises. A controller would need a predeclared independent signal and a fresh confirmation set; it must not optimize against the already monitored benchmarks.
