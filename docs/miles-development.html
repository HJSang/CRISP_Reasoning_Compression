cd CRISP_Reasoning_Compression/miles

Run Miles commands from that directory so package imports and relative paths match upstream. Follow Miles setup documentation for a compatible GPU environment. Environment installation is not performed by this repository import. Commit from the CRISP root as usual; no submodule update or separate Miles push is needed.

Research protocol remains under review

The planned study separates PI corrections from checkpoint differences and measures actual unhinted student learning. The inspected Miles OPD implementation uses sampled-token or top-k reverse-KL signals; it does not implement the earlier proposed full-vocabulary forward-KL experiment. The loss choice, run matrix, and compute budget must be settled explicitly in the experiment review.

This change establishes the source baseline and development location. It does not add the PI scorer, change the loss, install dependencies, or launch training. The existing upstream examples are reference implementations, not approval to start a full run. A bounded pilot and a full study have separate review gates.

Validation for the import checks the upstream Git tree against the tracked copy, including executable bits and symlink targets, and verifies that no nested Git repository or submodule was introduced. Runtime correctness of later experiment patches requires their own tests.
